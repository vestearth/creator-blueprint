# Keyboard Layout Master v1

- File: `keyboard-layout-master-v1.mp4`
- Format: H.264 MP4, 1920×1080, 30 fps, stereo AAC 256 kbps
- Runtime: 9:15
- Narration: local Kokoro-82M synthesis with Thai espeak-ng phonemization
- Music and sound design: procedurally generated by `tools/render-001-master-v1.mjs`
- Render command: synthesize the narration, then run `npm run render:001:master`

Narration is split and aligned to the ten sections in `script.md`. Generated narration
stems are ignored because they are reproducible and large. The local synthesis runtime
is intentionally not a project dependency; see the production notes in the storyboard
for the model and license record.

The verified local narration setup used Python 3.12 with `kokoro==0.9.4` and
`soundfile==0.14.0` in an isolated virtual environment:

```powershell
python -m venv .venv-tts
.venv-tts\Scripts\python.exe -m pip install kokoro==0.9.4 soundfile==0.14.0
.venv-tts\Scripts\python.exe tools\synthesize-001-narration.py am_fenrir
npm run render:001:master
```
