# AI Agent vs Chat — Lemon8 Carousel Draft v1

- Directory: `lemon8/`
- Files: `002-ai-agent-lemon8-01.png` through `10.png`
- Format: PNG, 1080×1440, sRGB working output
- Source: `assets/002-ai-agent/lemon8-cards.html`
- Theme tokens: `assets/002-ai-agent/tokens.css` (`ai-signal-map-v1`)
- Render data: `content/002-ai-agent/outputs/lemon8/cards.json`
- Render command: `npm run render:002:lemon8`

The carousel uses an AI-specific dark signal-map theme with original HTML/CSS
diagram primitives and bundled OFL fonts. It does not reuse the paper-and-blue
field-note treatment reserved for the Keyboard content family.
It is a review draft, not a publish-approved package. Human verification and final
editorial approval remain open gates.

Visual QA completed on 2026-09-21: all ten cards were inspected at 1080×1440 and
as a 5×2 sequence contact sheet. Card order, text clipping, contrast, and diagram
continuity passed the production review.
