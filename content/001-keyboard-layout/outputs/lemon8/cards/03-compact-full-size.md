# 96% / 98% / 1800 Compact

## On-card copy

**ยังมี numpad แต่บีบพื้นที่และย้ายบางปุ่ม**

- เก็บปุ่มส่วนใหญ่ของ full-size
- navigation และ spacing ต่างกันมากตามรุ่น
- คำว่า `98%` มีตัวอย่างทั้ง 97, 98 และ 99 ปุ่ม

ก่อนซื้อ: ซูมดู `Delete / Home / End / arrows / numpad`
