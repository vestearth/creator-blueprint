Keyboard 60%, 65%, 75%, TKL, 98% หรือ 100% ไม่ได้ต่างกันแค่ขนาด — สิ่งที่
กระทบการใช้งานจริงคือปุ่มไหนยังอยู่เป็นปุ่มแยก ปุ่มไหนถูกย้ายไป Fn/layer และเรา
ใช้ปุ่มเหล่านั้นบ่อยแค่ไหน

วิธีตัดตัวเลือกแบบเร็ว:

- ใช้ numpad ต่อเนื่อง → เริ่มที่ Full-size หรือ 96/98%
- ไม่ใช้ numpad แต่อยากได้ตำแหน่งคุ้นมือ → TKL
- ต้องใช้ F-row และลูกศร แต่ต้องการตัวเครื่องสั้นลง → 75%
- ต้องการลูกศร แต่รับการกด Fn สำหรับ F-row ได้ → 65%
- ให้ความสำคัญกับขนาดและพร้อมเรียนรู้ layer → 60%

ชื่อเปอร์เซ็นต์เป็นเพียงชื่อกลุ่มโดยประมาณ ไม่ได้รับประกันจำนวนหรือตำแหน่งปุ่ม
ก่อนซื้อควรเปิดภาพ physical layout และ keymap/manual ของรุ่นจริงทุกครั้ง

ตอนนี้เราใช้ layout อะไร และมีปุ่มไหนที่ขาดไม่ได้?
