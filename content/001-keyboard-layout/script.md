## Narration

### Hook

คีย์บอร์ดสองตัวนี้เขียนว่า “98%” เหมือนกัน

แต่ตัวหนึ่งมี 97 ปุ่ม อีกตัวมี 99 ปุ่ม

ถ้าเปอร์เซ็นต์เป็นมาตรฐานจริง เรื่องนี้ไม่น่าจะเกิดขึ้น แต่ในโลกของ mechanical
keyboard มันเกิดขึ้นเป็นปกติ เพราะตัวเลข 60, 65, 75 หรือ 98 เปอร์เซ็นต์ เป็นชื่อ
เรียกกลุ่มขนาดโดยประมาณ ไม่ใช่สูตรคณิตศาสตร์ที่ผู้ผลิตทุกเจ้าต้องทำตาม `(C-001, C-009)`

เพราะฉะนั้น ถ้าคุณกำลังเลือกคีย์บอร์ด อย่าเริ่มจากคำถามว่า “กี่เปอร์เซ็นต์ดีที่สุด”

ให้เริ่มจากคำถามว่า “ปุ่มไหนที่ผมใช้จริง และถ้าปุ่มนั้นหายไป ผมยอมกด Fn แทนได้ไหม”

คลิปนี้เราจะเริ่มจาก full-size แล้วค่อย ๆ ดูว่า เมื่อคีย์บอร์ดเล็กลง ปุ่มอะไรถูกตัด
อะไรถูกบีบ และอะไรไม่ได้หายไปไหน—แค่ถูกย้ายไปอยู่บน layer

### กติกาในการดู Keyboard Layout

ก่อนเทียบแต่ละขนาด ให้แบ่งคีย์บอร์ดออกเป็นห้ากลุ่ม

กลุ่มแรกคือปุ่มตัวอักษร ตัวเลข และ modifier ที่เราใช้พิมพ์ทุกวัน

กลุ่มที่สองคือ F1 ถึง F12

กลุ่มที่สามคือ navigation อย่าง Insert, Delete, Home, End, Page Up และ Page Down

กลุ่มที่สี่คือลูกศร

และกลุ่มสุดท้ายคือ numpad

เวลาคีย์บอร์ดเล็กลง กลุ่มแรกแทบจะยังอยู่ครบ สิ่งที่เปลี่ยนจริง ๆ คืออีกสี่กลุ่ม
ที่เหลือ ว่าจะยังเป็นปุ่มเฉพาะ ถูกลดจำนวน ถูกย้ายตำแหน่ง หรือถูกซ่อนไว้หลัง Fn

นี่เป็นวิธีดู layout ที่มีประโยชน์กว่าการจำจำนวนปุ่ม เพราะแม้ใช้ชื่อเปอร์เซ็นต์
เดียวกัน แต่ physical layout ของแต่ละรุ่นก็ยังต่างกันได้ `(C-001, C-011)`

### Full-size หรือ 100%

เริ่มจาก full-size เพราะมันเป็นแผนที่ที่เข้าใจง่ายที่สุด

โดยทั่วไปเราจะเห็นทั้ง F-row, navigation cluster, arrows และ numpad แยกเป็นสัดส่วน
ตัวอย่าง full-size ANSI รุ่นหนึ่งมี 104 ปุ่ม และกว้างประมาณ 435 มิลลิเมตร `(C-002)`

ข้อดีไม่ได้ซับซ้อน: ปุ่มหลักแทบทุกกลุ่มอยู่ตรงหน้า ไม่ต้องจำ layer เพิ่ม

ถ้างานของคุณมีการป้อนตัวเลขต่อเนื่อง ใช้ spreadsheet, accounting หรือ shortcut
ที่ผูกกับ numpad บ่อย ๆ full-size เป็นจุดเริ่มที่ปลอดภัย

สิ่งที่ต้องแลกคือพื้นที่แนวนอน โดยเฉพาะบนโต๊ะเล็ก หรือถ้าต้องการวางเมาส์ใกล้มือ
มากขึ้น คีย์บอร์ดกลุ่มนี้อาจกินพื้นที่ส่วนที่คุณไม่ได้ใช้จริง `(C-010, C-012)`

### 96%, 98% และ 1800 Compact

ถ้าคุณยังต้องการ numpad แต่คิดว่า full-size กว้างเกินไป กลุ่มต่อมาคือ 96%, 98%
หรือชื่ออย่าง 1800 compact

แนวคิดของกลุ่มนี้คือเก็บปุ่มส่วนใหญ่ของ full-size เอาไว้ แล้วลดช่องว่างระหว่าง
กลุ่มปุ่ม บีบ navigation cluster หรือย้ายบางปุ่มไปตำแหน่งใหม่ `(C-008)`

มันจึงเป็นทางกลางสำหรับคนที่ยังใช้ numpad แต่ต้องการตัวเครื่องสั้นลง

แต่คำว่า 96% กับ 98% ไม่ได้บอกทุกอย่าง รุ่นหนึ่งที่เรียก 96% อาจมี 100 ปุ่ม
ขณะที่รุ่นที่เขียนว่า 98% มีตัวอย่างตั้งแต่ 97 ถึง 99 ปุ่ม `(C-008, C-009)`

ก่อนซื้อ ให้ซูมดูตำแหน่ง Delete, Home, End, Page Up, Page Down, ลูกศร และ numpad
ของรุ่นจริง เพราะสิ่งที่ทำให้ต้องปรับตัวไม่ใช่ชื่อเปอร์เซ็นต์ แต่คือตำแหน่งที่มือ
ของคุณคาดว่าจะเจอปุ่มเหล่านี้

### TKL หรือ 80%

TKL ย่อมาจาก Tenkeyless ซึ่งแนวคิดหลักคือเอา numpad ออก แต่ยังเก็บ F-row, arrows
และ navigation cluster ไว้เป็นปุ่มเฉพาะ

ตัวอย่าง TKL รุ่นหนึ่งมี 87 ปุ่มและกว้างประมาณ 354 มิลลิเมตร เทียบกับ full-size
ตัวอย่างก่อนหน้าที่กว้างประมาณ 435 มิลลิเมตร เท่ากับได้พื้นที่คืนมาราว 8 เซนติเมตร
โดยยังไม่ต้องย้าย F-row หรือลูกศรไปอยู่บน layer `(C-002, C-003)`

ถ้าคุณแทบไม่แตะ numpad แต่ยังอยากได้ตำแหน่งปุ่มที่คุ้นเคย TKL เป็นตัวเลือกกลาง ๆ
ที่ปรับตัวน้อย และเป็น baseline ที่ดีสำหรับทั้งงานทั่วไป การเขียนโปรแกรม และเกม

แต่ถ้าคุณต้องป้อนตัวเลขเป็นชุดบ่อย การไม่มี numpad ก็อาจสร้าง friction ทุกวัน
ดังนั้นอย่าเลือก TKL เพียงเพราะโต๊ะของคนอื่นดูสะอาดกว่า

### 75%

75% พยายามเก็บสิ่งสำคัญของ TKL ไว้ในพื้นที่ที่สั้นลงอีก

โดยทั่วไปยังมี F-row และลูกศร แต่ลดจำนวนหรือบีบ navigation keys เข้ามาชิดกับ
ส่วนพิมพ์หลัก ตัวอย่างจากผู้ผลิตเดียวกันยังมีทั้ง 82 และ 84 ปุ่ม และบางรุ่นพิเศษ
ก็มีจำนวนต่างออกไป `(C-001, C-004)`

ข้อดีคือยังเรียก F1 ถึง F12 และลูกศรได้โดยตรง เหมาะกับคนที่ใช้ปุ่มเหล่านี้บ่อย
แต่ไม่ต้องการขนาดของ TKL

สิ่งที่ต้องลองคือ spacing และตำแหน่ง navigation keys เพราะเมื่อช่องว่างระหว่างกลุ่ม
หายไป การกดจาก muscle memory อาจไม่เหมือนคีย์บอร์ดเดิม

ถ้าคุณใช้ IDE หรือโปรแกรมที่เรียก F-row บ่อย แต่แทบไม่ใช้ numpad นี่มักเป็นกลุ่มแรก
ที่ควรลองก่อนลดลงไปถึง 65%

### 65%

65% คือจุดที่ F-row แบบ dedicated หายไป แต่ลูกศรยังอยู่

ตัวอย่าง 65% รุ่นหนึ่งมี 68 ปุ่ม มีลูกศรและ navigation บางปุ่ม ส่วน F1 ถึง F12
รวมถึงคำสั่งอื่นจะเข้าถึงผ่านการกดร่วมกับ Fn `(C-005)`

กลุ่มนี้จึงเหมาะกับคนที่อยากได้คีย์บอร์ดสั้นมากขึ้น แต่ยังไม่อยากย้ายลูกศรไปไว้
บน layer

คำถามสำคัญไม่ใช่ “65% เล็กพอไหม” แต่คือในหนึ่งวันคุณกด F-row และ navigation
keys ที่หายไปบ่อยแค่ไหน

ลองเปิดโปรแกรมที่ใช้ทุกวัน แล้วนับดูว่าคุณกด F5, F10, F11, Home, End หรือ Delete
แบบไม่ผ่าน shortcut อื่นบ่อยหรือไม่ ถ้าคำตอบคือบ่อย การกด Fn เพิ่มทุกครั้งอาจเป็น
ต้นทุนเล็ก ๆ ที่สะสมทั้งวัน แต่ถ้าแทบไม่ใช้ 65% อาจเป็นสมดุลที่ลงตัวมาก

### 60% และความหมายของ Layer

60% ลดลงเหลือแกนหลักสำหรับการพิมพ์ ตัวอย่างรุ่นหนึ่งมี 61 ปุ่ม และเข้าถึงลูกศร,
F-row รวมถึง multimedia ผ่าน key combinations `(C-006)`

ตรงนี้มีความเข้าใจผิดที่ควรแยกให้ชัด

การไม่มี dedicated key ไม่ได้แปลว่าฟังก์ชันนั้นหายไปจากคีย์บอร์ดเสมอ มันอาจอยู่
บน layer ซึ่งทำงานคล้ายปุ่ม Fn บน laptop: ปุ่มเดิมส่งคำสั่งอีกชุดเมื่อเราเปิด layer
นั้นอยู่ Firmware อย่าง QMK ยังรองรับทั้งการกด layer ชั่วคราว การ toggle และการทำ
ให้ปุ่มหนึ่งทำงานต่างกันระหว่างการแตะกับการกดค้าง `(C-007)`

ข้อดีคือได้ตัวเครื่องที่เล็กและพกง่ายขึ้น ตัวอย่าง 60% ที่ใช้ในงานวิจัยกว้างประมาณ
293 มิลลิเมตร เทียบกับ full-size ตัวอย่างที่ประมาณ 435 มิลลิเมตร `(C-010)`

สิ่งที่แลกคือ learning curve คุณต้องจำว่าลูกศร, F-row และ navigation อยู่ตรงไหน
และบางคำสั่งอาจต้องกดหลายปุ่มแทนปุ่มเดียว

ถ้าคุณชอบปรับ keymap และยอมฝึก muscle memory 60% ให้ workflow ที่เร็วได้ แต่ถ้า
คุณต้องสลับใช้คีย์บอร์ดหลายเครื่อง หรือไม่อยากจำ layer เพิ่ม ความเล็กอาจไม่คุ้มกับ
friction ที่เกิดขึ้น

### เลือก Layout จาก Workflow

แทนที่จะถามว่า layout ไหนดีที่สุด ลองตอบห้าคำถามนี้

ข้อหนึ่ง คุณใช้ numpad ป้อนตัวเลขต่อเนื่องบ่อยไหม

ถ้าบ่อย เริ่มดู full-size หรือกลุ่ม 96/98/1800 compact ถ้าไม่บ่อย TKL หรือต่ำกว่า
จะคืนพื้นที่ให้โต๊ะและเมาส์ได้ `(C-012)`

ข้อสอง คุณต้องกด F1 ถึง F12 แบบปุ่มเดียวบ่อยไหม

ถ้าบ่อย ให้เริ่มที่ TKL หรือ 75% ถ้าไม่บ่อยและยอมกด Fn ได้ ค่อยดู 65% หรือ 60%

ข้อสาม คุณใช้ Home, End, Page Up, Page Down, Insert และ Delete ตัวไหนเป็นประจำ

อย่าดูแค่ว่า “มี navigation keys” ให้ดูว่ารุ่นจริงเก็บปุ่มที่คุณใช้ไว้หรือไม่

ข้อสี่ คุณยอมเปลี่ยน muscle memory และใช้ layer ได้แค่ไหน

บางคนกด Fn กับปุ่มอื่นได้เป็นธรรมชาติ บางคนต้องสลับคีย์บอร์ดหลายเครื่องและอยากให้
ทุกปุ่มอยู่ที่เดิม ไม่มีคำตอบไหนผิด

และข้อห้า พื้นที่โต๊ะกับการพกพาสำคัญแค่ไหน

ความกว้างที่ลดลงมีประโยชน์ก็ต่อเมื่อพื้นที่ที่ได้คืนมามีค่ากับคุณจริง อย่าเสียปุ่ม
ที่ใช้ทุกวันเพื่อแลกกับพื้นที่ที่ไม่ได้ขาด

### สรุป

สรุปให้สั้นที่สุด:

ถ้าใช้ numpad บ่อย ดู full-size หรือ 96/98

ถ้าไม่ใช้ numpad แต่อยากได้ปุ่มแบบคุ้นมือ ดู TKL

ถ้าอยากเล็กลงแต่ยังต้องการ F-row และลูกศร ดู 75%

ถ้าต้องการลูกศรแต่ยอมให้ F-row อยู่บน Fn ดู 65%

และถ้าให้ความสำคัญกับขนาดมากที่สุด พร้อมเรียนรู้ layer ดู 60%

แต่ไม่ว่าจะเลือกกลุ่มไหน ขั้นสุดท้ายต้องเปิดภาพ physical layout และ keymap ของรุ่น
จริงเสมอ เพราะเปอร์เซ็นต์เป็นแค่ชื่อเรียกคร่าว ๆ ไม่ใช่สัญญาว่าปุ่มจะเหมือนกัน
`(C-001, C-009, C-011)`

ตอนนี้คุณใช้ layout อะไรอยู่ และมีปุ่มไหนที่คิดว่าขาดไม่ได้ ลองแชร์ไว้ได้ เพราะ
คำตอบนั้นมีประโยชน์กับคนที่กำลังเลือกระหว่างสองขนาดมากกว่าคำว่า “ตัวนี้ดีที่สุด”
