# Content Brief

## Audience question

คนที่กำลังเลือก mechanical keyboard ควรเลือก layout ใด และแต่ละขนาดต้องแลก
อะไรกับอะไรบ้าง?

## Viewer promise

เมื่อดูจบ ผู้ชมจะเข้าใจความแตกต่างของ layout หลักและเลือกขนาดที่เหมาะกับงาน,
พื้นที่โต๊ะ และการพกพาของตนได้ โดยไม่ต้องจำชื่อจากหน้าสินค้าอย่างเดียว

## Original angle

อธิบาย layout ผ่าน “ปุ่มที่หายไปแล้วกระทบ workflow อย่างไร” แทนการไล่ขนาด
ตามเปอร์เซ็นต์เพียงอย่างเดียว

## Why this channel should make it

หัวข้อนี้เชื่อมประสบการณ์ใช้งานอุปกรณ์ของ developer กับการตัดสินใจซื้อที่คนดู
นำไปใช้ได้จริง และเป็นเนื้อหา evergreen

## Scope

### Included

- 60%, 65%, 75%, TKL, 98% และ full-size
- ปุ่มที่คงอยู่หรือถูกตัดออก
- ผลต่อการเขียนโปรแกรม, งานตัวเลข, gaming, desk space และ portability
- วิธีเลือกจาก workflow ก่อนเลือกจากรูปลักษณ์

### Excluded

- รีวิว keyboard รุ่นใดรุ่นหนึ่ง
- switch, keycap profile, mounting style และ modding
- ประวัติของ keyboard layout

## Expected viewer action or understanding

ผู้ชมสามารถตัดตัวเลือกให้เหลือหนึ่งหรือสอง layout ก่อนเริ่มเปรียบเทียบรุ่นและราคา

## Visual feasibility and rights risks

ใช้ diagram และ animation ที่สร้างเองเป็นหลัก หลีกเลี่ยงภาพสินค้าที่ไม่มีสิทธิ์ชัดเจน
หากใช้ภาพผู้ผลิต ต้องบันทึก URL และฐานการใช้งานใน asset plan

## Success hypothesis

คลิปแบบ comparison ที่ตอบคำถามก่อนซื้อจะสร้าง search traffic ระยะยาว และช่วงที่
แสดง “ปุ่มใดหายไป” ควรรักษาผู้ชมได้ดีกว่าการอ่านรายการ specification
