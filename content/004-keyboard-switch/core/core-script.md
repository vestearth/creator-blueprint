# Canonical Narrative

Status: `verified-for-adaptation`

## Working title

Linear / Tactile / Clicky ต่างกันยังไง? เลือก Switch จากการใช้งาน ไม่ใช่แค่เสียง

## Audience promise

เราจะใช้ประเภท switch เป็นจุดเริ่มต้น แล้วดูข้อมูลที่กำหนด feel และเสียงจริงก่อนเลือก

## Hook concept

เวลาเลือกคีย์บอร์ด เรามักเจอคำว่า Linear, Tactile, Clicky หรือได้ยินว่าเสียง “Creamy”, “Thock”, “Clack” แต่ชื่อเหล่านี้ตอบได้เพียงบางส่วน ประเภทบอกว่าเราจะได้รับ feedback แบบไหนระหว่างกด; feel และเสียงสุดท้ายต้องดูมากกว่านั้น [C-001–C-003, C-007, C-009–C-010]

## Reasoning order

นิยามสาม feedback styles → อธิบาย force/travel และรายละเอียดแต่ละรุ่น → แยกเสียง switch จากเสียงคีย์บอร์ดทั้งตัว → เสนอวิธีเลือกที่เริ่มจาก preference และลองจริง

## Main explanation

Switch คือกลไกใต้ปุ่มที่ตอบสนองต่อการกดและส่ง input เมื่อถึงจุด actuation ใน mechanical keyboard แบบที่โพสต์นี้พูดถึง คำว่า **Linear / Tactile / Clicky** แยก *ลักษณะ feedback* ระหว่าง stroke มากกว่าจะเป็นคะแนนความเร็ว ความสบาย หรือเสียงทั้งคีย์บอร์ด [C-001–C-003, C-006]

**Linear** ไม่มี tactile bump หรือ click event ที่ออกแบบไว้ระหว่าง stroke จึงให้การเคลื่อนที่ต่อเนื่อง แต่ไม่ได้ไร้แรงต้านหรือไร้เสียง; เราอาจยังได้ยิน bottom-out และเสียงตอนปุ่มเด้งกลับ Linear สองรุ่นอาจต่างกันมากทั้งแรงกด ระยะกด spring วัสดุ รูปทรง และ lube [C-001, C-007] การชอบ stroke แบบนี้ไม่ได้จำกัดว่าเราต้องเล่นเกม

**Tactile** มี bump ที่นิ้วรับรู้ระหว่างกด โดยไม่จำเป็นต้องมี click mechanism รุ่นต่างกันอาจให้ bump เด่นต่างกัน; อย่าอนุมานจากคำว่า Tactile อย่างเดียวว่า bump จะเบา ชัด หรืออยู่ตรงตำแหน่งที่เราชอบ [C-002, C-008] การมี bump ก็ไม่ได้ทำให้เป็น “switch สำหรับพิมพ์งาน” โดยอัตโนมัติ

**Clicky** มีทั้ง tactile และ audible feedback จาก click mechanism ตัวกลไกสร้าง click ได้หลายวิธี เช่น click-bar กับ click-jacket จึงไม่ควรคิดว่าทุกตัวเสียงหรือ feel เหมือนกัน [C-003–C-004] เสียง click เป็นสิ่งที่ควรคำนึงเมื่อใช้ร่วมกับคนอื่น แต่ความเหมาะสมขึ้นกับสภาพแวดล้อมและความชอบของเรา ไม่ใช่กฎห้ามใช้ในงานใดงานหนึ่ง [C-012]

เมื่อรู้ว่าชอบ feedback แบบไหน ให้ดู **force** และ **travel** ต่อ ตัวเลข operating/actuation force บอกแรงที่จุดหนึ่ง ไม่ใช่ feel ตลอดทางหรือแรงตอนกดสุด; spring และความสัมพันธ์ระหว่างแรงกับระยะกดก็มีผล [C-005, C-007] **Pre-travel** คือระยะก่อนสวิตช์ส่ง input ส่วน **total travel** คือระยะกดทั้งหมด สองค่านี้ตอบคนละคำถาม [C-006] จากนั้นดูรายละเอียดรุ่น เช่น spring, bump/click mechanism, factory lube และ stem/housing material/geometry โดยหลีกเลี่ยงสูตรว่าใช้วัสดุ X แล้วต้องได้เสียง Y [C-004, C-007–C-009]

ตัวอย่างที่จับต้องได้: Gateron G Pro 2.0 Red และ Silver เป็น Linear และระบุ operating force เท่ากันที่ 45±15 gf แต่ Red มี pre-travel 2.0±0.6 mm / total travel 4.0 mm max ส่วน Silver 1.2±0.3 mm / 3.4 mm max [C-014] ตัวเลขนี้แสดงความต่างของระยะกดในสองรุ่น ไม่ได้พิสูจน์ความรู้สึกของทุกคนหรือแนะนำว่ารุ่นใดดีกว่า

ศัพท์ **Creamy / Thock / Clack** ช่วยบอกภาพเสียงที่คนฟังพยายามสื่อ แต่ในโพสต์นี้เราไม่ใช้เป็นประเภท switch หรือสเปกมาตรฐานที่เทียบข้าม build ได้ [C-010] ตามคำอธิบายของผู้ผลิต Switch มีส่วน แต่ keycaps, plate, mount, case, foam และการประกอบก็เปลี่ยน feel/เสียงได้ [C-009] คลิปเสียงหนึ่งคลิปยังได้รับผลจากแรงพิมพ์ โต๊ะ ห้อง และไมค์ จึงเป็นตัวอย่างการฟัง ไม่ใช่คำรับประกันว่าเมื่อซื้อ switch รุ่นเดียวกันแล้วคีย์บอร์ดเราจะได้เสียงเดียวกัน [C-011]

สีแดง Linear, สีน้ำตาล Tactile และสีน้ำเงิน Clicky เป็นภาพจำที่ช่วยเริ่มต้นได้ แต่สีไม่ได้เป็นกฎของทุก switch แม้ในแคตตาล็อกผู้ผลิตเดียวกันยังมีสีดำที่เป็น Linear, สีม่วงที่เป็น Tactile และสีเขียวที่เป็น Clicky [C-013] เวลาซื้อจึงอ่านประเภทและสเปกของ *รุ่นจริง* แทนการตัดสินจากสี

## Recommendation or conclusion

เลือกเป็นลำดับ: (1) อยากได้ stroke ต่อเนื่อง, bump ทางนิ้ว หรือ bump พร้อม click? (2) ลองน้ำหนักแรงกดและระยะกดที่สบาย (3) อ่าน spec และคำอธิบายของ *รุ่นจริง* (4) ดูคีย์บอร์ดทั้งตัวและที่ที่เราจะใช้ (5) ถ้าเป็นไปได้ ลอง switch tester หรือคีย์บอร์ดจริงก่อนซื้อ [C-012] แนวทางนี้เป็นวิธีลดความเสี่ยงในการเลือก ไม่ใช่สูตรว่าประเภทหนึ่ง “ดีที่สุด” สำหรับทุกคน

## Caveats

- โพสต์นี้เน้น mechanical switch แบบสัมผัสไฟฟ้าทั่วไป; magnetic/Hall Effect, optical และ low-profile compatibility มีรายละเอียดต่างกันและอยู่นอกขอบเขต
- ไม่มีประเภทใดเงียบสนิทหรือรับประกัน Creamy/Thock/Clack จากชื่อประเภทเพียงอย่างเดียว [C-001, C-009–C-010]
- คำบรรยาย feel/sound เป็นประสบการณ์เชิงคุณภาพ; หากยกสเปกรุ่นเฉพาะต้องตรวจหน้าผู้ผลิตใกล้วันเผยแพร่ [C-008–C-011]

## CTA intent

ชวนคนดูเล่าว่า feedback แบบใดที่นิ้วชอบ และสิ่งใดใน switch ที่อยากลองเทียบจริง แทนการโหวตว่าประเภทไหนชนะ
