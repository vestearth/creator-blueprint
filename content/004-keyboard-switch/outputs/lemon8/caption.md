# Caption

## Publish copy

เวลาเลือก Switch เราอาจจำจากสีแดง = Linear, น้ำตาล = Tactile, น้ำเงิน = Clicky ได้ก่อน แต่สีไม่ใช่กฎตายตัว ยังมีสวิตช์สีดำที่เป็น Linear สีม่วงที่เป็น Tactile และสีเขียวที่เป็น Clicky ด้วย จึงควรอ่านประเภทของรุ่นจริง

ถ้าชอบการกดต่อเนื่อง ลองเริ่มที่ Linear; ถ้าอยากรู้สึกจังหวะที่นิ้ว ลอง Tactile; ถ้าอยากได้จังหวะที่นิ้วพร้อมเสียงคลิก ลอง Clicky แล้วค่อยเทียบแรงกด ระยะกด และความรู้สึกจากของจริง

ส่วนคำว่า Creamy / Thock / Clack เป็นคำช่วยบรรยายเสียงที่ได้ยิน ไม่ใช่ประเภท Switch หรือผลลัพธ์ที่ switch ตัวเดียวรับประกันได้ เสียงจริงขึ้นกับ keycap, plate, mount, case, foam และวิธีพิมพ์ด้วย คลิปเสียงช่วยให้เห็นตัวอย่าง แต่ถ้ามีโอกาส ลอง switch tester หรือคีย์บอร์ดจริงก่อนซื้อ
